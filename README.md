# TaskFlow

A to-do list app UI. Add tasks with categories, tick them off, and review your pace on the calendar and stats pages. Frontend-only project, no backend.

## Stack

Vite + React 18 + TypeScript + Tailwind CSS + shadcn/ui

## What's inside

- Task cards with a quick-add modal and floating action button
- Category filter and sidebar navigation
- Calendar, stats and settings pages
- Light/dark theme (spaceship toggle)

## Develop

```bash
npm install
npm run dev     # dev server
npm run build   # production build
npm run lint    # eslint
```
